課程目標

本課程專為研究所學生設計，旨在深耕現代網頁前端技術架構。課程內容涵蓋 HTML5 語意化建構、CSS3 進階版面佈局（Flexbox/Grid）、JavaScript 非同步處理與 ES6+ 現代語法，並引導學生理解元件化開發思維與效能優化策略，培養具備實戰能力的進階前端開發人才。

教學大綱

  1. 現代前端工程概覽與開發環境建置
  2. 語意化 HTML5 與 Web accessibility (a11y) 規範
  3. CSS3 進階版面佈局：Flexbox 與 CSS Grid 實務
  4. ES6+ JavaScript 核心機制與 DOM 操作
  5. 非同步程式設計 (Promises, Async/Await) 與 API 串接
  6. 前端模組化設計與現代框架概念簡介
